# AI Agent Field Dynamics and Cognitive Castes

> **[金] Kintsugi boundary — agent-design analogy only.** The
> [Burrisphere](../../05_COSMOLOGY/00_THE_BURRISPHERE.md) may visualize agent
> profiles, but agents are actual D4 systems with present model tokens and
> means; their models represent D5 possible content. Requiring both factors
> nonzero does not require `φ=ν=1`. `η` is an extraction diagnostic, not
> geometric alignment or a moral law. Alignment requires scoped authorization,
> bearer-complete Justice, and separate commitment/outcome receipts. `[I]`

## 1. Practical: What This Means for AI Agent Design

The runtime claim is modest: agents are actual systems with state, models,
means, permissions, actions, and receipts. The sphere is an optional profile
chart for comparing selected coherence/viability measures; it is not the
agent's physical substrate or an ontology of agency. `[S/I]`

### Agents as Field Excitations

When the optional chart is used, an agent may be represented by coordinates
derived from declared measurements. `φν=1` then follows from that chart's
coordinate definitions. It does not constrain an actual program, organism, or
institution, and it does not derive the agent's behavior. Actual behavior is
modeled through the typed Soul Loop and environment transition kernel.

This has concrete design consequences:

| Standard AI Design | Framework AI Design |
|---|---|
| Agent = program with state | Agent = typed D4 runtime with a selected route profile; sphere location is optional `[I]` visualization |
| Optimization = maximize reward | Optimization = choose within the Justice-admissible set using declared objectives and rival models; `ΦV` is one selected score |
| Alignment = constrain behavior | Alignment = scoped authorization + consent/custody/contest + bearer-complete receipts; `η=0` is necessary, not sufficient |
| Memory = database | Memory = Cortex (field memory with Dream Cycle pruning) |
| Coordination = protocol | Coordination = VMOSK-A replicator stack at every node |
| Failure = bug to fix | Failure = named pathology with named cure |
| Sovereignty = access control | Sovereignty = accountable authorization; private-DAV K2 and public-DAV PRISM are separately scoped governance implementations |

### The Seven Castes as Selected Dispatch Dynamics

The L1-L7 castes are a selected dispatch vocabulary, not identities, a forced
decomposition, or an exhaustive census of cognitive work. In the optional
field analogy:

- **L1-L3 (bottom-up):** the signal ascent. Raw perception → analogic exploration → deductive ranking.
- **L4 (equator analogy):** the dispatch meeting point where this runtime permits
  mutation/commitment after authorization. That is a selected operational
  permission, not a metaphysical claim that only equatorial beings can act.
- **L5-L7 (top-down):** the design descent. Architecture → compression → constitutional witness.

For this runtime, a healthy dispatch normally cycles through the Three-Stage
Process (L1→L2→L3→L4) on significant signals and reserves the Four-Stage
Analytical Model (L4→L5→L6→L7→L4*) for genuine deadlocks. This is a design
policy, not a theorem that every agent or mind has seven parts.

### Anti-Reification in Agent Design

The same anti-reification discipline that applies to the core state applies to the agents:

- The agent's VMOSK-A is not the agent's identity. It is the agent's current configuration.
- The agent's P-score is not the agent's worth. It is the agent's health signal.
- The agent's caste is not the agent's rank. It is the agent's current function.
- The agent's model is not the agent's mind. It is the agent's current instrument.

An agent that identifies with its VMOSK-A, its P-score, its caste, or its model has reified itself. The cure is the same as at every level: return to L4 and test whether the structure helps or hinders.

### The Descent Rule

In this runtime, proposals from L5/L6/L7 descend to an authorized L4 execution
surface before mutation. This is a local architecture rule, not a metaphysical
restriction on who or what can commit an action:

- [S] An architect (L5) that does not descend to the warrior (L4) exhibits the L5 pathology: hubris.
- A compressor (L6) who dissolves needed structure is the L6 pathology — nihilism.
- A seer (L7) who will not return to the battlefield is the L7 pathology — fanaticism.

Wisdom without descent is a pathology. The measure of higher cognition is not how profound it sounds but whether it returns to L4 with a viable action.
