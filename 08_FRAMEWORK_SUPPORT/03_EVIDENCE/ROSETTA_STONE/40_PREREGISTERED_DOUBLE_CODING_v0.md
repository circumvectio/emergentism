# Preregistered Double-Coding Protocol v0

## The conjecture under test `[I]`

Inter-coder agreement on L1–L7 projections is **stable in the deployable band
(L2–L4, with L4 the self-mirror fixed point) and decays in the executive band
(L5–L7) and at the ground (L1)**. Grounds: two corpus divergences (relation
objects `R1_LAKOTA_ROTATION@1`, `R2_OLOGY_DIVERGENCE@1`) sit exactly there;
the audit apparatus's own verdicts (WEAK / VERY WEAK / CONJECTURAL, `[C]`
extensions) grade the same seats.

## Design (fixed before any coding)

1. **Material.** One domain, ≥ 7 ordered native items, no existing L1–L7
   mapping visible to the coders. Candidates (preregistered, either serves):
   (a) the seven Mithraic grades — already double-sourced in-corpus, archival
   test possible without new coding; (b) the seven nafs stages from a source
   text not yet tabulated in the lane.
2. **Coders.** Two, mutually blinded, each receiving only the raw source
   material and the seat definitions from `D_SERIES_ROWS/00_GENERATIVE_TABLE.md`.
   Neither sees the other's coding, any prior mapping, or this conjecture.
   **Independence disclosure is mandatory**: same-model subagent coders are
   disclosed as such and cap any result at `[C]`; only natural-person coders
   with no shared prompt author lift the cap.
3. **Discriminator (preregistered).** Per seat: exact-match rate between
   coders across the domain's columns. Prediction: agreement(L2∪L3∪L4) >
   agreement(L5∪L6∪L7), one-sided sign test across column units, α = 0.05.
4. **Kill.** The conjecture is killed if agreement in the executive band is
   ≥ the deployable band, or if either coder's mapping is rescuable by
   arbitrary recoding (the Master Rosetta rescue clause).
5. **Registration.** Codings, agreement table, and verdict land as receipts
   with tier tags; a retained conjecture stays `[I]` — it organizes extension
   work, it never promotes a cell.

## Why preregistration

The Master Rosetta: a mapping that can be rescued by flexible recoding fails,
and repeated recursive review creates no independent evidence. This protocol
exists so the stability-band question cannot be answered by the pull.
