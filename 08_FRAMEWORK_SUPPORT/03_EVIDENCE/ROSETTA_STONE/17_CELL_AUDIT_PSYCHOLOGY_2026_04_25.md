## Cell Audit: L1 — Survival / Sensorimotor / Pre-conventional / Physiological-Safety

| Field | Content |
|---|---|
| **Cell ID** | `L1__Psychology__Survival` |
| **L-level** | L1 |
| **Operator** | Kali 🎲 (demon) |
| **Domain expression** | Piaget: Sensorimotor. Kohlberg: Pre-conventional. Maslow: Physiological / Safety needs. Sanskrit virtue: Prāṇa (life force). Shadow: Terror / Rage. |
| **Evidence tier** | **[S]** Piaget's sensorimotor stage (0–2 years) is independently validated. Kohlberg's pre-conventional is validated but built on Piaget. Maslow's physiological/safety needs are universal (Tay & Diener 2011, n=60,865). |
| **Source basis** | Piaget (1936, 1954); Kohlberg (1958, 1984); Maslow (1943, 1954); Tay & Diener (2011) |
| **Fit reason** | Sensorimotor cognition is body-bound, object-permanent but not abstract. Pre-conventional morality is punishment-avoidance. Physiological needs dominate attention. All three describe **existence at the margin** — the organism before social abstraction. |
| **Adjacent check** | L1→L2 transition: Sensorimotor→Pre-operational = emergence of symbolic thought. Pre-conventional→conventional boundary = first social rules. Physiological→Belonging = needs expand beyond survival. Adjacency holds. |
| **Mirror check** | L1 ↔ L7: Terror/rage (L1 shadow) ↔ Fanaticism/bypassing (L7 shadow). Both are boundary pathologies — one from below (existential threat), one from above (transcendent capture). Mirror holds. |
| **Kill criterion** | If sensorimotor cognition is shown to continue into adulthood (it does, tacitly), this does not kill the mapping — it means L1 is a permanent substrate, not a stage to be left behind. |
| **Cell verdict** | **STRONG** |
