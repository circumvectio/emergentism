# Separation Operator Protocols — Historical Prototype

> **[金] Kintsugi seam.** The predecessor described illustrative Python-like
> fragments as substrate-agnostic executable operators, assigned moral effects
> to mythic labels, and used irreversible sacrifice, reputation, termination,
> and mesh membership without a complete authorization or bearer ledger. Those
> fragments were never an implementation and are not current doctrine.

## Standing

This path preserves the fact that bounded operator workflows were explored. It
does not supply runnable code, deployment authority, a safety case, or evidence
that an archetype name determines an action's consequence or moral status.

The following predecessor assumptions are withdrawn:

- that an agent "is the mesh" or that a boundary is illusory;
- that permanent personal loss automatically creates global value;
- that reputation can verify genuine contribution;
- that equatorial alignment earns operation rights;
- that a mythic termination operator is a constitutional kill switch; and
- that any pseudocode can authorize irreversible resource, capability,
  identity, or life-affecting action.

## Reusable workflow boundary

The current G7 vocabulary may label an already scoped D4 action or posture. It
does not create the action. Any implementation must instead expose:

```text
actual state -> modeled D5 alternatives -> accountable authorization
-> commitment receipt -> performed D4 action -> environmental outcome receipt
-> map and selector update
```

Every materially affected bearer must remain visible, including payer,
beneficiary, principal, mandate, actor, consent, custody, reversibility,
revocation, contest, exit, and consequence. Voluntary sacrifice is a distinct
costly class, never proof of goodness and never strict syntropy by relabeling.

An implementation belongs in an owning code repository with ordinary tests,
permissions, threat modeling, and rollback. This philosophy directory may
describe types and failure modes but cannot activate a runtime.
