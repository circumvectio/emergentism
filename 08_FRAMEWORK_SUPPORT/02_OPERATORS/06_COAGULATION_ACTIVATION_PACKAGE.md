scoped engineering:

- a user or accountable principal supplies a mandate and scope;
- an owning repository supplies code, dependencies, permissions, and tests;
- consequential acts require complete accountable authorization;
- commitment, action, and environmental outcome receipts remain distinct;
- all materially affected bearers retain consent, custody, contest, and exit;
  and
- no symbolic operator, Rosetta row, model score, or philosophical text grants
  a machine authority over people or systems.

A future software package must be proposed and reviewed in its actual owning
code lane. Its performance and safety claims must be measured there. This file
cannot bootstrap it by description.
