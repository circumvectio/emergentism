## §3 · The generator, identified

There is no single source file. The relation is **structurally required** by four
distinct framework concepts, and each is independently re-introducing it:

1. **The simulation's visual cycle** (`SIMULATION_SPEC.md`, 9 asserts). The six
   animations show dimensional emergence D0→D5, with **D6→D0 (closure, [S]) as the
   return to the dot**. The cycle is the whole point of the visual; without the
   closure there is no ouroboros, only a line.

2. **The dimensional ladder's boundary** (`23_DIMENSIONAL_CLOSURE_PROOF.md`,
   `41_UNIFIED_DIMENSIONAL_DERIVATION.md`, `25_STEEL_THREAD.md`). A strict ladder
   `D0 < D1 < … < D5` needs a closing move or it is open-ended. The relation provides
   the closing move; the proofs and the derivation use it as the boundary.

3. **The papers' axiom** (`AX3_THE_SCAFFOLD.md`): *"Reality unfolds D0→D6; each level
   emerges at its μ-limit (saturation); D6→D0 (closure, [S])."* The peer-review
   program's paper form is published with the relation as a stated axiom.

4. **The audit stack** (107, 110, 63, 137, 126, 131, 73, 133, 116). Each audit
   re-raises the question because the previous resolution was **STAGED, not ADOPTED**.
   The audit pattern is: notice the recurrence, propose a fix, stage the fix, move on.
   The next audit finds the same recurrence and proposes the same fix.

This is why four repairs have not ended the recurrence. **The repair is at the
occurrence level; the relation is at the framework level.** Removing individual
assertions does not affect the four generators above; they re-emit.

## §4 · Three readings the corpus already owns

Receipt 73 (Brāhmaṇa structural audit, 2026-05-04) named the three readings:

1. **Strict identity under order** — `D0 < D1 < … < D5 < D6` and `D6 = D0` together
   imply `D0 < D0`, a contradiction. REFUTED on its face (126, 131).
2. **Apophatic return `[I]`** — the cycle returns, but the return is a
   *category change*, not an identity. Survives as the tilde-rescue `D6~D0`.
3. **Boundary / wrap-around** — the cycle is a closed curve, not a ladder, and the
   "D6 = D0" statement names the identification made by the wrap. This is the
   simulation-spec and the dimensional-closure-proof reading.

The corpus has the three readings stated. It does not have a **standing rule for which
reading wins in which context**. The K2 (Yves) has not ratified reading (2) or (3) as
the canonical form, and so each surface picks its own.

## §5 · Why the tilde-rescue is not the answer

The tilde form `D6~D0` (34 live uses) is the corpus's preferred survival shape — but
**the literal relation keeps re-asserting in parallel**, and the tilde itself
co-occurs with the literal in 8 files. This is the same pattern at a smaller
amplitude: a partial fix that doesn't reach the generator.

## §6 · Disposition, proposed

Two paths close the recurrence. The corpus must choose one.

**Path A — Adopt the closure as canonical, state it once, fence the rest.**
- Promote reading (3) — "the cycle returns by a wrap, the wrap makes the
  identification, this is the simulation's and the ladder's boundary" — to a stated
  axiom in `06_ONTOLOGY/03_THE_EMERGENT_AXIOMS.md`, marked `[S]` (the wrap is a
  declaration, not a derivation).
- Replace all 73 literal asserts with the new canonical form (e.g., `D6 → D0 (wrap, [S])`
  or the tilde `D6~D0` if reading (2) is preferred).
- Tilde-rescues: keep, but tie to the canonical form so the literal and the tilde
  cannot drift apart again.
- Standing fence in `check_d6_equiv_d0.py` (proposed in §7): fails the build if the
  LITERAL `D6≡D0` form appears anywhere outside the canonical statement, with both
  mutations tested.

**Path B — Retract reading (3) entirely, keep reading (2) as the only `[I]` form.**
- Add `D6 ≡ D0` (any literal form) to the corpus's barred-claims list. The
  `check_barred_claims.py` already exists; add the pattern.
- Replace all 73 literal asserts with the tilde-rescue `D6~D0` marked `[I]`.
- Drop the simulation's ouroboros visual or rename it (e.g., "the cycle returns" without
  naming the identification).
- Standing fence in `check_d6_equiv_d0.py`: fails the build on any live literal
  `D6≡D0` form. This is the corpus's stricter read and the one most consistent with
  `06_ONTOLOGY/03_THE_EMERGENT_AXIOMS.md`'s *"forbids … literal D6≡D0"*.

**Both paths end the recurrence. Path B is cheaper to land and more consistent with
the ontology file's current stance. Path A is more honest about the framework's
actual use of the relation. The choice is the K2's.**

## §7 · Standing fence — proposed, not yet written

A `check_d6_equiv_d0.py` script in `09_TOOLS/01_SCRIPTS/` that:

1. Scans every live `*.md` for the LITERAL `D6≡D0` form (`[≡=↔≅]`, with or without
   spaces) and any of the three or four most common space-permitted variants.
2. Fails the build if any literal form appears outside the canonical statement
   (whichever the K2 ratifies).
3. Tests the tilde-rescue explicitly: `D6~D0` is permitted in the chosen context,
   forbidden in others.
4. Two mutations tested:
   - **MUT-1:** canonical statement removed → FAIL.
   - **MUT-2:** literal `D6≡D0` introduced into a clean surface → FAIL.
5. Pin the canonical text by exact byte match — the same anti-shielding pattern used
   in the F2-withdrawal guard.

The script lands with receipt **190** in this series, after the K2 chooses Path A or
Path B.
