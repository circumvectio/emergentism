# Custody receipt

The complete pre-v2.3 public `amrita/` and `halahala/` bundles were copied
byte-for-byte into this archive before their generated successors were allowed
to replace them. `MANIFEST.sha256` binds every archived relative path.

The original Git state and these copies provide two recovery paths. Supersession
does not withdraw the historical arguments, failures or provenance. It only
changes which projection owns the current public routes.

Rollback restores the public bundles from this directory or from commit
`8b07e00c`, then restores the prior withholding, redirect and service-worker
state. This archive and the successor notice remain after rollback.
