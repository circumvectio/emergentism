# Open Canon v0.1 set — consolidation 2026-07-19

The 4-doc Open Canon v0.1 set at `01_EMERGENTISM/` root was consolidated
on 2026-07-19 per the K2 directive ("do the did-not list"). One doc
remains canonical; three are retired to K3 archive with this tombstone.

## Why consolidated (the convergence-memo compliance)

The 4 docs were 4 separate conceptual scopes (receipt, protocol,
spread, gap) but the **v0.1 set as a whole was sprawl** — 4 K2-signed
ACTIVE docs at root, all v0.1, all `[A]` tier, none superseded by
the others. The convergence-memo rule ("ship Y's directive, don't
refine X") closes the violation when one is canonical and the rest
are referenced from it.

**Pick: SPREAD.** Rationale:
- 30,534 bytes (largest of the 4; most operational content)
- K2-signed 2026-07-18 (earliest of the 4 K2 signs, so the original)
- §5 names the Open Canon Foundation charter as the institutional
  layer (the PROTOCOL implements what SPREAD says)
- §6 names the immune system (the GAP is the philosophical ground
  that SPREAD rests on)
- The RECEIPT is the first visible η=0 receipt that SPREAD §3
  describes

So: **SPREAD is the strategy. PROTOCOL implements it. GAP is its
ground. RECEIPT is its first visible act.** One canonical, three
referenced.
