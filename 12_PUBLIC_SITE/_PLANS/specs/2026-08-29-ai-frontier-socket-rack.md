# The Frontier

## One-page job

Let a human or machine choose one of the twelve existing Grand Puzzle gaps and
inspect the same bounded research object: source owner, canonical execution
requirement, public routing state, native recovery, no-placement rival,
discriminator, kill, survivor, and current receipt absence.

## Atelier decision

Three fictional, unaffiliated directions were considered:

1. **Socket Rack** — strongest portfolio selection and fit with the existing
   twelve-gap routing spine.
2. **Research Object Envelope** — strongest custody and human/machine parity.
3. **Discriminator Gate** — strongest falsifier emphasis but too narrow as the
   whole Frontier.

The selected composition uses the Socket Rack as the only primary interaction.
Opening one native disclosure reveals a Research Object Envelope. The
Discriminator Gate survives as a labelled field inside that envelope, not as a
second interaction or a simulated result.

## Material grammar

- The page begins with the number **12** as an inventory, not a completeness
  claim.
- Long horizontal rules form a rack; native `<details>` elements form sockets.
- Newsreader carries each human question. Roboto Mono carries addresses, states,
  hashes, and endpoints. Roboto carries explanation.
- Actual contract bytes are solid gold; candidate contact remains blue;
  conjecture is violet and dashed; returned evidence is mint and appears only as
  a labelled empty position until a real receipt exists.
- No sphere, chat theatre, code rain, mock terminal, glowing endpoint, streaming
  field, or continuous motion appears. Burrisphere alone owns the sphere as a
  mathematical instrument.

## Responsive and access contract

At 320px the rack becomes a single readable column. The socket ID and title stay
visible; secondary status compresses; the open object stacks in the same semantic
order. Every target is at least 48px, the complete content exists without
JavaScript, colour is redundant with labels and line styles, reduced motion is
static, hashes wrap rather than overflow, and Exit remains direct.

## Content cuts

The route does not restate the worldview, Finity practice, benchmark protocols,
fundraising pitch, contribution form, or complete trial record. It links to their
owners. Machine access is an ordinary static file retrieval, never a live job or
inference promise.

## Kill criteria

Revise or remove the route if one gap cannot be selected and fully inspected at
320px without JavaScript; if public routing is confused with canonical execution;
if a candidate, test, receipt, or revision is implied to exist when its namespace
count is zero; if source hashes or human/machine fields diverge without a failing
check; if it implies live jobs, sensor intake, payment, credentials, institutional
authority, totality, or designer affiliation; or if the page weakens Exit.
