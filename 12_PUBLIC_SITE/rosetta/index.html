01 · The discipline

Similarity proposes a bridge; it never supplies the bridge’s warrant.

Rosetta is useful precisely because it refuses to declare every resemblance an identity.

Native description
State what the source domain itself establishes, with its own variables, assumptions, and evidence.
Typed projection
Name the relation being proposed: analogy, structural correspondence, operational reuse, or conjectured mechanism.
Preserved difference
Record what cannot cross: ontology, units, causal force, moral status, authorization, or proof.
Discriminator
Say what observation or formal result would distinguish the projection from a rival or forced fit.
Return
Let native evidence revise the mapping. Never modify a source merely to make the rows align.

Correspondence is not confirmation. Cross-domain or cross-model convergence may reveal a useful invariant, shared ancestry, selection bias, or elegant freezing. Only discriminating contact separates those possibilities.

07 · Translation returns

The Rosetta Stone is finished only when the world can correct it.

A beautiful table is still only a model.

Generate rival translations. Ask whether common ancestry or a forced vocabulary explains the fit. Choose the cheapest discriminating test. Record what fails and what survives. Then amend the stone without rewriting the native source.

That return is the Soul Loop: territory → model → alternatives → selection → commitment → consequence → revision.
