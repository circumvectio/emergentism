# Fair Re-Adjudication Protocol

> The prior instrument was rigged. 18/18 refutations, `refuted: true` as the
> default prompt, a running tally poisoning each round. That is a ratchet,
> not a panel. This protocol corrects it.

## The design errors in the prior instrument

1. **`refuted: true` as DEFAULT.** Every referee prompt instructed "your
   default is refuted." A referee whose default is one verdict is not a
   referee — it is a prosecution. The corpus's own rule: *"a guard that
   cannot fail is worse than no guard."* This guard could only fail.

2. **Running tally.** Each new panel received "SEVEN refuted… EIGHT…
   NINE…" — a thumb on the scale that gets heavier each round. No honest
   panel arrives with a prior conviction count.

3. **"Already owned" ≠ "false."** Roughly half the 18 verdicts established
   prior art, not falsity. For a project whose stated mission is *"its good
   if other people had the same ideas, our mission is not to be the first"*
   — "already owned" is a **citation task**, not a kill.

## The fair protocol

**Referee instructions:**
- Build the strongest case FOR the claim.
- Build the strongest case AGAINST the claim.
- Deliver one of four verdicts:

| Verdict | Meaning | Action |
|---|---|---|
| **STANDS** | The claim is true as stated, at its stated tier | Cite and keep |
| **STANDS WITH CITATION** | The claim is true but is prior art; the corpus did not invent it | Cite the source; keep the claim; do not assert novelty |
| **NEEDS REPAIR** | The claim has a real defect (false as stated, ill-typed, circular) but a corrected form survives | Repair in place; keep the correction receipt |
| **KILLED** | The claim is false and no corrected form survives | Tombstone with reason |

**No default. No running tally. No prior conviction count. Each claim
adjudicated on its own merits, blind to the others' outcomes.**
