# Emergentism: full-stack audit

## 1. Decision

**[I] Keep the architecture; improve the path from an important question to a usable, revisable answer. Do not start another independent application stack.**

Emergentism can supply an independently readable worldview and an instrument for examining claims. The lower products should supply intake, evidence, forecasts, proposals, memory, disclosure and interface capabilities. They do not establish the worldview's truth, and reading it must not require using them.

**[D/B] The current local site is not a verified release candidate.** Its 18-section public predeploy check passes, but the deterministic site-artifact check fails and the wider corpus gate reports multiple failures. A Practice interaction also produces a stale prepared packet after the underlying decision is edited. Private connected operation has not been demonstrated by this audit.

**[I] Best next increment:** repair those integrity defects, then prove one small correction round-trip using existing lower-level capabilities. Judge the added complexity against ordinary documents/search and a simple decision journal. Another comprehensive visual rewrite is not the first dependency.

## 3. What is worth preserving

1. **[S/I] A worldview with actual source owners.** The public explanations can point to declared premises, inherited mathematics, interpretations, conjectures, rivals and remaining explanatory debt. Internal answers and external validation are separate states.
2. **[S/I] A useful distinction between possibility and actuality.** A represented alternative is not its execution; a proposal is not authorization; a receipt is not an outcome assessment. Preserve these distinctions in the UI as well as the prose.
3. **[S/I] A practical, revisable decision record.** Affected bearers, actual means, alternatives, review horizons, signals, cost and Exit can be made inspectable. Comparative decision benefit remains a test, not a consequence of the vocabulary.
4. **[B/I] Negative results remain visible.** The corpus contains failed comparative trials and surviving narrower claims. That is usable research material, not a reason to hide the worldview or a proof of its superiority.
5. **[B] Publication custody is substantially implemented.** The public checks report 419 lifecycle-classified artifacts with zero unclassified, 199 withheld artifacts under custody, and 75 declared public surfaces matching HEAD. These are different denominators, not additive route counts.

The settled canon remains controlling: D0–D6 is selected and separately conjectured as a natural decomposition; the reciprocal chart identity is not a node-power law; the selected node score is ordinal `min`; ethics is not proved from geometry; F5 remains a separately testable wager. This audit makes no changes to those claims.

## 4. Build on the lower levels, without making them a compulsory pipeline

The mapping below is **[I] product architecture**, not a derivation of seven natural or institutional ranks. Capabilities are reusable dependencies; not every question needs every row.

| Role | What Emergentism should reuse | Boundary / observed readiness |
|---|---|---|
| L1 — APU | Bounded source intake, retrieval, source inspection, relevance, abstention and qualification preservation | Source preparation is not truth certification. APU also has an L5 reasoning function; it is not a second product. Local capabilities exist, but this audit does not establish a connected Emergentism embedding. |
| L2 — Circle | Maintained investigations and sourced `SignalPacket` / IS when a claim needs evidence work | A source assertion is not a forecast or an action approval. Do not rebuild Circle inside the worldview site. |
| L3 — RealityFutures | Uncertainty-bearing `ForecastPacket` / COULD, assumptions and calibration | Only invoke where a discriminating prediction is meaningful. A likelihood does not become normative SHOULD. |
| L4 — Agentz | Bounded unsigned `ProposalEnvelope` / SHOULD and explicit execution boundaries | The inspected applied planner is unmounted/undeployed and does not itself run agents. Reuse the contract without claiming live actuation. |
| L5 — Menexus | Cortex proposals/accepted history, Nexus permitted context and new AIA interaction | Existing Python carrier is real code, not merely an old TypeScript sketch. Supported contract subsets, real issuer/session admission and privacy still need exact integration tests. |
| L6 — Skyzai-whole | HOLD, RETURN or non-authorizing PASS at the consequence boundary | No refusal found is not human approval; no machine signature or authority follows. |
| L7 — Emergentism | Worldview, source orientation, claim distinctions, questions, counterexamples, portable practice | It does not own all storage, search, workflow or policy; it cannot certify itself through the products applying it. |

External authority, consent, rights, scope and outcome evidence remain distinct from this table. Cortex acceptance is a reviewed record state, not a truth decree or public release. Nexus owns disclosure; an APU consumer must not recreate or bypass that decision.

The existing [workbench plan](../../../00_HANDOFF/EMERGENTISM_APU_MENEXUS_WORKBENCH_PLAN_2026_09_07.md) already expresses this separation. Prefer finishing its first slice to creating competing ownership, another backend, another AIA, a copied APU interface, or a DLT requirement for public reading.

### EFA-01 — P1: prepared Practice packet becomes stale without warning [B]

**Source:** [Practice preparation and signing state](../../12_PUBLIC_SITE/practice/index.html), lines 563–612.

**Reproduction:** enter decision A; prepare unsigned transaction; change the decision field to B. The field shows B, while the prepared receipt and fingerprint still describe A. Copy/download remain enabled and the status still invites review/sign/revision. No signing was attempted in this audit. This is a local integrity defect, not evidence of a real-world unauthorized transaction.

**Proposed repair:** make draft revision, prepared immutable snapshot and acknowledgment visibly separate states. Any material edit invalidates preparation/acknowledgment or explicitly preserves a clearly labeled old snapshot. Guard asynchronous fingerprint results against later edits and overlapping preparation.

**Pass:** edit every semantic input after preparation; race two preparations; clear while hashing; revise after acknowledgment. Only the exact visible revision can be exported or acknowledged as current. Add browser regressions; the existing focused suite did not catch this behavior.

### EFA-03 — P1 before private integration: public worker is not a private-workspace boundary [B/I]

**Source:** [service worker](../../12_PUBLIC_SITE/sw.js), lines 669–725; workbench plan lines 259–263 and 309.

The current worker handles almost every same-origin GET, admits responses unless `Cache-Control` includes `no-store`, and deletes every other CacheStorage name on activation. Public production CSP also permits inline scripts and broadly permits HTTPS connections. **No private data leak was observed**; the inspected site is static. Reusing this setup unchanged for private work would contradict the plan's already-written cache/privacy requirements.

**Proposed repair:** pin a private host/worker/CSP boundary. A separate private origin is the simplest candidate; an alternative must demonstrate equivalent isolation. Limit public caching to public assets and cleanup to owned cache names. Do not rely on robots/noindex for access control.

**Pass:** deny wrong project, consumer, purpose, expired/revoked session and reconnect; test snippet/citation/existence leakage, browser cache/offline behavior, logout, export and deletion. Public worker upgrade must neither retain private responses nor remove unrelated application caches.

### EFA-05 — P2: concrete value arrives after a large conceptual commitment [B/I]

The homepage's ordinary example is in section 06, after the dimensional spine, hinge, stack, wisdom and instrument. `/plainly/` still introduces several symbolic systems early. At 1280×720 the homepage is approximately 12,638 CSS pixels high; at 390×844 approximately 20,519. Length alone is not a usability failure, but a visitor must traverse much vocabulary before testing usefulness.

**Proposed structure:** a short promise and ordinary example; choose a philosophical question or practical inquiry; see the answer, source, qualification and rival; take a small next step; then unfold the full worldview. Reuse the existing three reading depths rather than add more routes. Keep the Burri sphere as an explanatory instrument with static text, not an entrance exam. Do not force the seven-fold into navigation.

**Pass:** unfamiliar readers can explain the offer, locate one supported distinction and its limit, and perform a useful next step without adopting the vocabulary or registering. Freeze success criteria before comparing this structure to the current site and a plain-document control.

### EFA-06 — P2: “Ask the book” promises more than lexical retrieval establishes [B/I]

**Source:** [book retrieval](../../12_PUBLIC_SITE/assets/js/book-ai.js), lines 68–110 and 167–192.

This is local BM25 retrieval, not model reasoning. It correctly declares “corpus passages only” and no external endpoint, but calls results “The corpus answers in its own words.” The query “Has the fifth force been experimentally proved?” returns a useful qualified F5 result first, alongside unrelated geometry and duplicate refutation results. Fixed 180-character excerpts do not guarantee that the source's qualifications survive. Failed index loading has no user-facing rejection handler in this path.

**Proposed repair:** label “Related passages” unless an exact qualified answer contract is satisfied. Show owner, revision, tier, relevant scope and unresolved question; preserve negation and uncertainty; group duplicate source views; surface fetch/parse failure and offer a plain source route. Reuse improved APU retrieval when its host contract passes, not a second privileged assistant.

**Pass:** frozen relevant, unrelated, contradictory, false-premise and unanswerable queries; score source/qualification recovery, justified abstention and correction cost. Lexical match, confident prose and cross-model agreement are not truth scores.

### EFA-07 — P2: return-to-practice and exact-source links are incomplete [B/I]

Practice invites a later return but the current form has no save/import or resume path; navigating away loses unexported input. This can remain intentionally ephemeral, but that contract must be conspicuous. A downloaded text packet is not an editable restoration path. Practice links to `/book/#6-tragic-decisions`, whose anchor does not exist; the public link gate nevertheless passes. Several named book-source links converge on a generic source index.

**Pass:** explicit temporary versus saved modes; restore the exported format or provide an intentional manual-return workflow; test route fragments and direct claim-source links, not just file existence. No silent conversion to Menexus persistence.

### EFA-08 — P2: public, programme and brand versions need one adoption decision [D/I]

The site still uses its Emergentism v2 design contract and local Newsreader/Roboto system. VMOSK-A v3, the machine-instrument successor and the workbench plan have evolved beyond that presentation. The current Skyzai guide is 8.0.12, while its release explicitly retains consumer token adoption pinned at 8.0.7. Therefore “use the latest brand guide” is not a sufficient release instruction.

**Pass:** source-owned consumer profile names the admitted guide/token versions, typography, modes, accessibility and public/private surfaces. Refresh the September 7 brand HOLD against current ownership; do not infer universal consumer adoption from a guide release. Keep the worldview, machine-method proposal and application programme distinguishable without creating parallel front doors.
