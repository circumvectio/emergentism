# Diagnostics and kills

Measure selected source-line coverage and unique returned lines, separately for
the original and assisted channels. Do not call these semantic accuracy or
comparative superiority: assistance and reading burden differ, and the key does
not enumerate every equivalent warrant. Nonempty refusal context can be useful.
No-hit behavior is not proof of source absence. Record any missed qualification.

Reject an output that drops or satisfies a requirement, changes the original
strict result, mismatches source bytes/ranges/hashes, makes a provider/network
attempt, changes inputs, or differs on repeat. The legacy default report and
the `--browse` report/navigation must match the predecessor output in full;
changed implementation receipt hashes are expected and kept separate.

The exact engine, snapshots, requests and raw outputs are preserved in a local
gzip archive. `run.mjs --check` replays that archive in a new directory without
depending on the old temporary capture folder. These are local process checks,
not an OS sandbox, source authentication, semantic truth or a connected Soul
Loop. The A3 frozen-record HOLD remains; no recorder is called or bypassed.
