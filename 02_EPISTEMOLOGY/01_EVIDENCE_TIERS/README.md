# 01 Evidence Tiers

This sublane owns the distinction among attested fact `[A]`, bounded built or
verified receipt `[B]`, consequence inside declared premises `[S]`,
interpretation `[I]`, draft `[D]`, and conjecture `[C]`.

Read [The Honest Position](00_THE_HONEST_POSITION.md) first, then
[The Honesty Protocol](THE_HONESTY_PROTOCOL_STANDALONE.md) for the compact
practice form.

This lane does not own formal proofs, public rhetoric, permissions, or action
authorization. Those are different types. It owns the rule that no canonical,
published, beautiful, useful, or authorized claim silently rises above its
evidence.

The predecessor evidence compilation is preserved in the pure-boundary archive;
it is genealogy, not a second owner.
