# Final Emergentism Folder Outline

## Decision

The final corpus should have **one worldview door, one kernel index, seven
chosen kernel surfaces in their owning lanes, and one inspectable trial
record**. This is an editorial architecture, not a proof that reality or every
knowledge domain is sevenfold.

This pass changes **semantic authority only**. It does not move or delete any
file. In particular, it makes no change under `90_ARCHIVE/`,
`91_COMPATIBILITY/`, `12_PUBLIC_SITE/`, or
`11_UPLINK/60_SESSION_PACKETS/`. A later custody pass must verify content,
hashes, inbound links, and provenance before any path changes.

## Phased cleanup contract

### Phase 0 — semantic authority `[S]` in this pass

1. Root front door and Kernel Index control navigation.
2. Owner documents control definitions, formulas, tiers, and kills.
3. Contradictory live files receive an explicit `[金]` seam or status tombstone.
4. Historical content remains readable in place.

### Phase 1 — custody inventory `[D]`

For each candidate, record blob hash, size, current status, active owner,
semantic delta, unique content, inbound links, and proposed verdict. A duplicate
name or old date is not enough to infer redundancy.

### Phase 2 — bounded moves `[D]`

Move one doctrine family at a time only after its inventory is accepted. Leave
a stable tombstone at every moved public or heavily linked path. Never combine
an archive move with a doctrinal promotion in the same unexplained act.

### Phase 3 — route repair and verification `[D]`

Validate Markdown links, source paths, frontmatter statuses, negative searches,
and protected-tree invariants. Run the stranger test from `README.md` through
the front door and K-1–K-7 without relying on oral context.

### Phase 4 — separately governed publication `[D]`

Public-site, compatibility-tree, and release changes form their own scope with
their own evidence and receipt. Internal semantic cleanup does not publish or
deploy itself.

## Done condition

The folder is clean when a stranger can:

1. find the worldview in one click;
2. distinguish theorem, structural definition, interpretation, wager, and
   receipt;
3. locate one active owner for every load-bearing claim;
4. inspect the wound that produced every `[金]` seam;
5. see that D4 is actual and D5 possible, with `μ0...μ4`, non-`μ` `κ`, and
   interpretive `r6` used consistently;
6. identify who bears and may contest a consequence without appealing to a
   worldview sovereign; and
7. put the map down without losing access to their work or the record.

This outline is not an eighth kernel surface. It is the proposed shelf on which
the seven chosen surfaces remain findable.
