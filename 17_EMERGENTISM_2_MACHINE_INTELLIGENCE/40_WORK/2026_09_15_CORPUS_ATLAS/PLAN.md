### Existing capability and limitations at planning

strict search, separate navigation and proposal history. Reuse it. Markdown scope
is not an all-artifact census. Fragment-local lexical candidates in processing
order are not globally ranked answers. Nominal collection inspection currently
creates/chmods a lock and opens SQLite read-write.

path components and has bounded file/batch sizes. It cannot yet consume every
collection source. Engine changes invalidate old collection hashes; `successor`
is not an engine migration.

Cortex staging preserves proposals and conflicts; the latest dated Titans run
has zero real human acceptance sessions. The accepted consumer projection omits
some source identity, locator and rights fields; complete downstream qualifier
delivery is unproved.

The Rosetta recorder last reported frozen-reference HOLD. Preserve it, never
rewrite expected hashes or claim a completed recorded Soul Loop. It does not
prohibit unrelated bounded engineering.
