# PROP — The six gates test patterns individually but not the independence of their source

## The surface (quoted)

02_WHEN_PATTERN_BECOMES_CANDIDATE_CLAIM.md §2 defines six gates a pattern must
pass individually to become a candidate claim. §4 adds selection-bias controls
for the Rosetta's cross-domain structure. Neither addresses the case where
**multiple patterns from the same source** pass all six gates independently but
share a common defect inherited from the source itself.

## The observation [I]

If one witness produces three patterns, and each pattern passes the six gates
individually, the gate mechanism gives no reason to distrust any of them. But if
the witness has a systematic blind spot — a disciplinary assumption, a sensor
limitation, an ideological frame — all three patterns may inherit the same
invisible defect. The six gates test the pattern, not the pattern's *origin*.

This is the kernel's own `convergence-as-proof` check (DF-15) applied at the
gate level rather than at the claim level: *are N agreeing candidate claims
independent, or one source's bias shown N ways?* The defect taxonomy names this
shape; the gate mechanism does not test for it.

## The proposed refinement

Add a seventh gate:

### Gate 7: Source Independence `[I]`

**Question:** If this witness produced other patterns that passed the gates, are
those patterns independent, or do they share a common defect inherited from the
witness's assumptions, instruments, or framing?

| Pass | Fail |
|---|---|
| This pattern's origin is independent of other gated patterns from the same witness, or the witness's assumptions have been audited and no shared blind spot was found | Other gated patterns from this source share an assumption, limitation, or framing that this pattern also carries — the independence of the gates was illusory because the source's bias runs through all of them |

**Note:** this gate does not require the pattern to come from a *different*
source — only that the source's systematic properties have been examined. A
single witness may legitimately produce multiple independent patterns if their
assumptions differ.

## dies_if

This proposal dies if: (a) the existing Gate 1 (Source Provenance) already
requires source-assumption auditing at a depth that makes this gate redundant —
Gate 1 requires traceability, not assumption-audit, so (a) is unlikely; or
(b) a worked counterexample shows that six individually-passing patterns from a
biased source are nonetheless all sound despite the shared bias — which would
mean shared-origin bias is not inherited by derived patterns.
