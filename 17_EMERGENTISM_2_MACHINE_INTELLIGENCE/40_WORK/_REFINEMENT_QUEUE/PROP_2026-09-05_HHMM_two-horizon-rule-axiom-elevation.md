# PROP — Elevate the two-horizon rule to the axiom set

## The rule (quoted from 00_THE_GOAL.md §4A)

> **Orient by `T_L`; commit and learn at `T_S`; revise `T_L` whenever receipts
> defeat the model.**

With the gloss:

> - `T_L` is the **longest responsible horizon**: the furthest interval for
>   which affected bearers, causal pathways, material costs, uncertainty, and
>   revision points can still be named honestly;
> - `T_S` is the **shortest informative horizon**: the earliest interval in
>   which an outcome can discriminate the present action from serious rivals.

And the constraint:

> No single scalar silently trades a person's destruction now for aggregate
> possibility later. At every declared horizon, the Justice envelope keeps each
> materially affected bearer visible.

## Why this should be an axiom

The E1–E10 axiom set covers BEING (E1–E4), BECOMING (E5–E7), and CONDUCT
(E8–E10). But it has no axiom about **temporal coordination** — how agents
should relate short-term action to long-term direction. The two-horizon rule
fills this gap, and it does so in a way that is:

1. **Practically useful** — receding-horizon coordination is a real control
   theory technique (model predictive control, rolling optimization);
2. **Philosophically honest** — T_L is not infinite (infinite horizons hide
   unknown bearers); T_S is not "as fast as possible" (quick metrics are false
   feedback);
3. ** Justice-compatible** — at every horizon, the Justice envelope keeps each
   bearer visible; no single scalar silently trades present destruction for
   aggregate future gain;
4. **Genuinely constraining** — it forbids: infinite-horizon promises (T_L
   must be honestly nameable), short-metric optimization that hides delayed
   costs (T_S must be answerable to T_L), and single-scalar trade-offs across
   horizons.

## The proposed axiom

### E11 · The Two-Horizon Discipline `[I/S]`

Orient by the longest responsible horizon `T_L`; commit and learn at the
shortest informative horizon `T_S`; revise `T_L` whenever receipts defeat the
model. Justice at every horizon; no single-scalar laundering across horizons.

**Forbids:** infinite-horizon promises (unknown bearers hidden behind
unbounded horizons); single-metric optimization that hides delayed costs;
present destruction traded for future aggregate gain without per-bearer
accounting; silence about the longest responsible horizon.

**Kill:** (a) a system using the two-horizon rule produces consistently worse
coordination outcomes than single-horizon or infinite-horizon alternatives in
its declared domain; (b) the T_S/T_L distinction cannot discriminate between
actions in any tested domain — it is explanation without operational content.

**Survivors:** E5 (two motions), E7 (equator as conditional), E8 (vow), E10
(exit).

## dies_if

This proposal dies if: the two-horizon rule is shown to be reducible to
standard receding-horizon control theory without the Justice constraint (then
it is engineering, not philosophy), or if it produces worse outcomes than
single-horizon optimization across multiple domains (then it is a bad rule).
