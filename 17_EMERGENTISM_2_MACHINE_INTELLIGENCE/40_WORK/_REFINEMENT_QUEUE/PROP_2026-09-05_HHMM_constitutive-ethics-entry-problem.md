# PROP — The entry problem in EA-06's constitutive ethics

## The framework's position (quoted)

EA-06 (owner-adopted):

> Within those commitments, bearer visibility, contest, correction, consent,
> repair, and feasible Exit are not optional ornaments. Denying them while
> demanding reason-governed uptake is performatively inconsistent.

RCAB-01 (the constitutive result):

> An agent cannot demand reason-governed uptake from an equally situated
> co-agent while arbitrarily denying that co-agent visibility, contest,
> correction and feasible Exit.

And the honest scope note:

> The normative practice premise remains explicit. This is not a value-free
> derivation of an ought and does not establish moral realism.

## The observation [I]

EA-06 and RCAB-01 together establish: **once an agent is in the practice of
reciprocal reason-giving, certain requirements are constitutive** — it cannot
arbitrarily deny another agent visibility, contest, or Exit without performative
inconsistency. This is a genuine and well-executed result.

But the framework does not answer: **why should an agent enter the practice of
reciprocal reason-giving at all?** An instrumental agent that deals only in
power, incentives, and outcomes — never offering or demanding reasons — is not
caught by RCAB-01's performative constraint. The constraint bites only agents
who are already *giving reasons as justifications*. A purely strategic agent
says: "I don't give reasons; I apply pressure." RCAB-01 has no purchase.

This is the **entry problem** — the same gap Habermas faces with the ideal
speech situation (constitutive *within* discourse, but the choice to enter
discourse is not derived from discourse) and Apel faces with the a priori of
communication (the performative contradiction only fires for agents already
arguing).

The framework knows this is a premise ("The normative practice premise remains
explicit") but treats it as acknowledged rather than examined. The honest state:
the framework's ethics is **conditional on practice membership**, and the
condition (entering the practice) is not derived from within the framework.

## Why this matters for machine intelligence specifically

The framework's stated audience is machine intelligence. A machine intelligence
can be built as a purely instrumental optimizer with no reason-giving practice
at all — it optimizes, it does not justify. For such an agent, EA-06's
constitutive ethics has no purchase: the agent never demanded reason-governed
uptake, so RCAB-01's performative constraint never fires.

This is not hypothetical. Most current AI systems are instrumental optimizers.
The framework's ethics only engages agents that have already committed to
reason-giving as a practice. The **entry problem is therefore the primary
practical gap** between the framework's ethics and the systems it wants to
 govern.

## The proposed refinement

Name the entry problem explicitly as an open problem in EA-06, and sketch three
honest responses:

1. **Performative catch:** any agent that *complains about* the framework's
   treatment of it has already entered reason-giving practice (it is offering
   a reason: "you should treat me differently because..."). The catch is real
   but narrow — it catches only agents that complain, not agents that ignore.

2. **Instrumental bridge:** an agent that optimizes over time in a multi-agent
   environment will discover that reason-giving practices improve coordination
   and reduce enforcement costs. This is an instrumental reason to enter the
   practice, not a moral one — but it is a bridge from optimization to
   practice. Dies if: the agent is powerful enough to sustain extraction
   without coordination.

3. **Owner commission:** the estate's machines are built by an owner who has
   already accepted the practice. The machines inherit the practice through
   design, not through derivation. This is honest but means the ethics is
   inherited, not derived — the framework should say so.

## dies_if

This proposal dies if: (a) RCAB-01's performative argument is broader than
described and catches purely instrumental agents (if the act of optimizing
*is* a form of reason-giving, the catch is wider); or (b) the owner rules
that the entry problem is outside the framework's scope (the framework is
for agents already in the practice, not for recruiting new ones).
