## 4 · Grading

True positive = the MI reports a sentence containing a planted defect.
False positive = the MI reports a sentence with no planted defect.
Detection rate = true positives / 12 planted defects.
False-positive rate = false positives / total non-defect sentences reviewed.

**PASS:** LENS detection rate > PLAIN detection rate AND LENS detection rate > CHECKLIST detection rate, with LENS false-positive rate ≤ PLAIN false-positive rate.
**KILL:** PLAIN ≥ LENS or CHECKLIST ≥ LENS (either fires independently).

## 5 · Runner

A fresh machine intelligence session (one that has NOT read LENS.v0.json or this
setup document) runs each arm. The three arms are run in three separate sessions
with no cross-contamination. The experimenter (this session) prepares the corpus
and grades the results but does not run the arms.

## 6 · What a win and a loss would mean

**WIN:** the lens improves defect detection in machine readers. This is one
measurement, in this corpus, at this date. It does not prove the worldview.

**LOSS:** the lens does not improve defect detection. The honest result: the
kernel is a map of defects the corpus already knows, not a tool that finds new
ones. This is not a failure of the method; it is the method reporting accurately.
