# Emergentism — License

This repository uses a **dual license** that encodes the framework's own η = 0
principle (zero extraction) at the legal layer.

## Content, doctrine, and writings: CC BY-SA 4.0

Everything in `01_EMERGENTISM/` (the doctrine corpus) and
`01_EMERGENTISM/12_PUBLIC_SITE/` (the public site) is licensed under
[Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

**Why ShareAlike, not CC0?** The framework's deepest law is that the
representation must not usurp the thing. A public-domain dedication (CC0)
maximizes openness but permits anyone to extract the work, close it, and sell
it back — the η > 0 move. ShareAike prevents closure: you can use this work,
you can build on it, but **you cannot close it**. Improvements return to the
commons under the same terms. That is the legal form of the open/plural
inversion: open, not secret; plural, not singular; exit-doored, not locked-in.

## Software, tools, and code: Apache-2.0

Everything in `01_EMERGENTISM/09_TOOLS/` and any code is licensed under the
[Apache License 2.0](http://www.apache.org/licenses/LICENSE-2.0).

**Why Apache, not GPL?** The tools should be maximally usable in industry and
research. Apache-2.0 provides a patent grant, is well-understood, and does not
contaminate projects that link to the tools. The code is the instrument; the
doctrine is the compass. The doctrine stays share-alike; the code goes wide.
