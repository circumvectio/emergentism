# Option-cone notation amendment `[D]`

No new glyph. Φ keeps its name. `⊙ = ○(•)` is unchanged. `⊙ = • × ○` stays retired.

This file does not rewrite the Canonical Formula Block. It stages a register split and a reading of `○`.

## 1 · Glyphs — three, unchanged in number `[I]`

```text
•   pure potential          no cone yet; absence held
○   THE OPTION CONE         the reachable set under a declared model M
⊙   the finite actual       a realized worldline inside ○

⊙ = ○(•)                    the generative event — existing formula, unchanged
```

**`○` becomes the option cone.** This refines the v3 assignment (`52` §1: ○ as diagonal-act / process-infinity / all generativity) rather than replacing it: the cone **is** generativity written extensionally — generativity as a set instead of an act. Same glyph, same role, now with a shape.

Option cone, never the physical light cone (`CLAUDE.md` / `00_INTELLIGENCE_AND_THE_POTENTIAL_CONE.md`).

**Open question for the chair (the only line that would change what an existing glyph *means*):** `⊙` was already the composite — a dot inside a circle *is* an actual inside a cone. `52` :71 already says the glyph is the picture of the composition: the point, enclosed. This file asks whether the enclosing ring is to be read as the space of what could have happened instead. Depiction is mnemonic, never a derivation (DF-20).

Not `Φ`. The letter is a shadow. Shadows name; they do not depict. Renaming Φ is refused: cost is estate-wide, DF-05 travels with the letter, and the picture is already owned.

## 2 · Two levels, because the Closure Rule requires it `[S]` rule / `[I]` readings

```text
TITAN LEVEL — boundary labels. Never an operand.
  •   ○   ⊙

REGISTER LEVEL — shadows. Legal operands, all ∈ [0,1].
  w              the realized worldline,  w ⊂ ○
  Φ₅  = μ(○₅)    measure of the D5 cone
  Φ̂₄  = Eval₄(M, Φ₅)     the cone as evaluated now, under model M
  V₄             viability of w
  P₄  = min(Φ̂₄, V₄)
```

ASCII: `cone`, `worldline`, `Phi5`, `Phi4_hat`, `V4`, `P4 = min(Phi4_hat, V4)`.

`min(○, V)` stays **forbidden** — a Titan in an operand slot (`52` :193). Measure the cone; operate on the measure. The glyph is the thing; the letter is its shadow; only shadows enter arithmetic.

## 3 · The typing law that makes `min` non-arbitrary `[A]` given the setup / `[S]` aggregator family

```text
w ⊂ ○           the worldline lies inside the cone, always
μ(w) = 0 in ○   the actual is measure-zero in the possible
```

**Φ is a measure of a set. V is a property of a path in that set.** Different types. No substitution exists between them, so no amount of Φ produces V and no V enlarges Φ. AND-class is forced by typing, before anyone selects an aggregator. `min` is `[S]` over that family (leximin also refuses substitution).

`μ(w) = 0` is `[A]` given the setup: the possible has volume; the actual has none inside it. The gloss “the Forms are real as possibles; they do not exist” is `[I]` and is not a numbered tenet claimed here.

`w` is selected by constraint, never pulled by an attractor (DF-19).

## 4 · What is not changed

`•` and `⊙` as marks: untouched until the chair answers §1. `⊙ = ○(•)` untouched. `Φ`, `V`, `P` keep their names. The verbatim analytic block in `00_CANONICAL_FORMULA_BLOCK.md` untouched.
