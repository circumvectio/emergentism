## 1. What the mathematics establishes `[A]`

For `θ∈(0,π)`, define

```text
φ=cot(θ/2)
ν=tan(θ/2).
```

Then `φν=1`. This is a coordinate identity.

For the unit sphere and

```text
A(ν₀) := {p∈S² : ν(p)≥ν₀},  ν₀>0,
```

elementary integration gives

```text
Area(A(ν₀)) = 4π/(1+ν₀²).
```

Hence `Area(A(ν₀))→4π` as `ν₀→0⁺` and `Area(A(ν₀))→0` as
`ν₀→∞`. The sphere does not collapse; the selected region shrinks and the
coordinate chart approaches a pole.

Likewise, `B=sin θ` tends to zero at **both** poles. It cannot uniquely select
one pole as an ontological beginning or end.

On a torus, a poloidal coordinate is `2π`-periodic by definition. Assigning
framework stages to that coordinate does not derive the stages or their return.
The Hopf fibration has an `S¹` fiber over every base point; it provides no
singular closure mechanism.

These facts are exact and useful. None entails a D-ladder.

## 4. Why literal closure failed

The old assertion that the endpoints were identical combined incompatible relations:

- If `D0<…<D6` is a strict order, identifying the endpoints yields a cycle and
  destroys strictness.
- Coordinate degeneration is chart behavior, not intrinsic dimensional loss.
- Torus periodicity is built into the chosen torus and therefore cannot prove
  that nature has seven stages.
- Equal values of `B` at two boundaries do not make those boundaries identical.
- A label placed at `2π` returns to the same coordinate by convention; that
  proves the convention, not an ontology.

The repair is to type the relations: positive candidate emergence (`μ`),
closure witness (`κ`), and interpretive resemblance/return (`~_I`,`r₆`) are
different.

## 5. Emergence status

No crossing is strongly emergent merely because its reduction is unknown. Each
`μ_n` must declare an order parameter, threshold, newly effective variable,
lower recovery map, reduction status, rival, prospective prediction, and kill
criterion.

A successful reduction changes that crossing to weak emergence; it does not
erase the useful scaffold. A candidate-strong classification requires
prospective evidence against named lower-only rivals and remains revisable.

The statement “there is no sixth positive freedom” is therefore a current
census wager `[C]`. It is killed by a demonstrated, operationally distinct
freedom beyond D5—not merely by inventing another name.

## 6. Domain projections

Mappings such as

```text
ground → matter → bond → life → mind → choice → return
```

are `ρ_domain` projections `[I/C]`. Each target domain must supply its own
definitions and evidence. The projection neither proves that each transition is
irreducible nor that the same number of stages exhausts every science.

Quantum interpretations are likewise optional analogies. Everett is a
no-fundamental-collapse relative-state formulation; Copenhagen-family
actualization is interpretation-specific. Neither is an additional spacetime
dimension, and neither proves `κ` or `r₆`.
