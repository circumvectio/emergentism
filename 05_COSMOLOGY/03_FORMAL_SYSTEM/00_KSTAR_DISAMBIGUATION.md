# η AND K* DISAMBIGUATION

**Status:** Canonical notation repair
**Date:** 2026-07-19

> **[金] Kintsugi seam.** The prior text printed a quantity named `K*` while
> calling it `η`, treated one extraction formula as universal, and claimed
> `η>0` was strictly dominated and `η=0` geometrically required. The repaired
> extraction owner proves none of those universal results. This document now
> separates the symbols and their evidence. The prior body is preserved in Git
> blob `c498b1428bbccda3ce8127a03faca01d1805ec46`.

## 1. `η` — Domain-Declared Extraction Diagnostic

Bare `η` names a **family** of extraction diagnostics. A valid use declares:

- substrate and protected bearers;
- payer and beneficiary;
- measured flow or loss;
- units, normalization, interval, and uncertainty;
- consent, custody, reversibility, and contest context;
- prediction and kill criterion.

One domain may define, for example,

```text
eta_spec := sum_i max(0, Delta nu_i^ext)
```

but that is `eta_spec` for that fixture, not the definition of `η` everywhere.
`η≈0` means only that the declared instrument detected no net extraction. It
is necessary but not sufficient for Justice. `η>0` does not by itself prove
immorality or authorize retaliation; `η<0` does not prove hidden costs absent.

No general theorem establishes `η=0` as a real equilibrium or `η>0` as
strictly dominated. The narrow Balance Game has a dominant central strategy
only because its payoff excludes extraction benefits. A fully specified game
with side payments can reward extraction.

**Tier:** `[S]` for the notation family; `[I/C/B]` for a particular instrument
until validation and receipts justify more.

## 2. `K*_{sel}` — Selection-Set Size

If a finite candidate set and equivalence relation are explicitly declared,
the framework may define:

```text
K*_{sel} := log2(number of admissible equivalence classes)
```

This is a framework measure `[I]`, not standard Kolmogorov complexity. A value
of zero says only that the declared candidate set has one admissible class; it
does not prove a structure is uniquely forced by reality.

## 3. `K_U(x)` — Kolmogorov Complexity

For a fixed universal description language or machine `U`, `K_U(x)` is the
length of the shortest program that outputs `x`. This is standard algorithmic
information theory `[A/B]`; values depend on `U` up to an additive constant.
It must never be written as `η` or silently equated with `K*_{sel}`.

## 4. Closed Notation Table

| Symbol | Meaning | Scope | Tier |
|---|---|---|---|
| `η` / `eta_spec` | declared extraction diagnostic family / one specification | domain operationalization | `[S]` vocabulary; fit varies |
| `K*_{sel}` | log size of a declared admissible selection set | framework measure | `[I]` |
| `K_U(x)` | shortest-description length relative to `U` | algorithmic information theory | `[A/B]` |

These quantities do not share one proved “self-containment” law. Any proposed
crosswalk is removable `[I/C]` and transfers no theorem.
