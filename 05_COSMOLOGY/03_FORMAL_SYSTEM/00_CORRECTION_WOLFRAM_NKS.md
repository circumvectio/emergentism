# Computational compression boundary

The former note opposed Wolframian computational irreducibility with “maximum
reducibility,” treated `S²` as a minimal description of reality, and used
`κ=0` as though the scaffold reconstructed the world. None follows from the
reciprocal chart.

What survives:

- `φ=cot(θ/2)` and `ν=tan(θ/2)` imply `φν=1` on their declared domain `[A]`.
- A finite formal system may compress some descriptions more economically than
  another `[A/S]`, once language, coding, and comparison class are fixed.
- Whether a specified dynamical system is computationally irreducible requires
  a defined computation, input family, resource measure, and proof or test.
- Neither an empty string, `0`, `1`, `∞`, nor `S²` outputs reality without a
  separately specified generative semantics.

The Burri grammar may therefore be studied as a compression lens `[C]`. It is
not a proof of minimum description length, a self-writing dictionary, a Theory
of Everything, or an empirical reconstruction of the territory.
