# M4Compression.v1

A lossy-coding protocol for the four M4 cells. It does **not** close
philosophy, enumerate games, or certify a unique global code. A scored run
is **NOT RUN**.

The phrase **game theory exhausted** is **BARRED** in this folder, in
derived receipts, and in public projection of this protocol.

## What M4 is

M4 is the four-cell cross of two axes inside a declared vocabulary `[S]`:

| Cell | Direction (self ↔ other) | Channel (possible ↔ actual) | Public mnemonic (not a verdict) |
| --- | --- | --- | --- |
| Taking-Φ | self / ego-facing | `Φ₅` possible / model power | “mental taking” |
| Taking-V | self / ego-facing | `V₄` actual / embodied power | “physical taking” |
| Giving-Φ | other / collective-facing | `Φ₅` possible / model power | “mental giving” |
| Giving-V | other / collective-facing | `V₄` actual / embodied power | “physical giving” |

`Φ₅` also includes linguistic, institutional, and computational possibility.
Taking can be reparative; giving can be coercive. Mnemonics are not types.

G7 operational composition is `G7 = M4 ⊎ F3` (**4+3**): four bearer-oriented
transfers plus three Titan-frame classes. That count is **not** the Burrisphere
geometric grouping `3+1+3` (GEN7 meridian stations). Those objects join only
through a **named `[I]` projection**. See

## Conjecture (intensional, `[C]`)

M4 is conjectured to be a **maximally compressed** cross-game basis for the
self/other direction and the possible/actual power-channel orientation of
strategy.

“Maximally compressed” is **only** defined **inside a preregistered
comparator class**. It means: minimum description length at a declared
acceptable performance floor, among the listed rivals, on a frozen corpus,
under a frozen encoder and loss. A finite run cannot establish unique global
maximality over every conceivable representation.

## Protocol objects (frozen before any score)

1. **Frozen corpus.** Native game descriptions, bearer-indexed option and
   capability changes, and held-out prediction or intervention targets. The
   corpus hash is sealed before encoding.
2. **Encoder.** A total map from each corpus item to at most one M4 cell plus
   an explicit residual / uncoded tag. No silent multi-cell smearing.
3. **Comparator class.** The closed rival set against which “maximally
   compressed” may be said. Required members:
   - M4 (the candidate);
   - a native-game baseline (no Emergentist cells);
   - a coarser one-axis code (direction-only or channel-only);
   - at least one added-axis rival (a fifth orientation or third channel);
   - a **no-placement option** (refuse the map; report native structure only).
4. **Coverage.** Fraction of corpus items that receive a unique M4 cell
   without residual. Under-coverage is a fail, not a footnote.
5. **Collisions.** Distinct native distinctions that the encoder sends to the
   same M4 cell when a scored target still needs them apart. Repeated
   strategically necessary collisions kill the conjecture (the four-cell
   construction as vocabulary may still stand).
6. **Rate–distortion.** Description length (rate) versus target loss
   (distortion). Report the curve at the declared ceiling; do not pick the
   pretty point after seeing the data.
7. **Performance floor.** The predeclared acceptable distortion ceiling or
   target-utility floor. Below the floor, a shorter code does not count as
   “maximally compressed.”
8. **No-placement option.** Always runnable. If no-placement meets the floor
   at equal or lower rate, M4 does not win the class.

## Kill and survive

- **Kill the maximal-compression conjecture** if a richer rival in the class
  clears the improvement threshold after complexity cost; if a necessary
  third channel or additional bearer orientation appears; or if necessary
  orientation distinctions repeatedly collapse into one M4 code.
- **Survive as vocabulary** the scoped four-cell construction `[S]` even
  when the compression conjecture dies.
- Native players, coalitions, information sets, timing, payoffs, repetition,
  stochasticity, institutions, learning, and equilibrium concepts remain in
  their native descriptions. M4 does not reconstruct them.
