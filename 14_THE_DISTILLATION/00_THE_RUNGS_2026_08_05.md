## IV. Foreclosed — the best word in the corpus

What is `a/0`?

- **"Undefined"** — *understates.* It suggests an unfilled slot, a value someone declined to assign.
- **"Forbidden"** — *overstates.* It suggests an agent doing the forbidding, a rule imposed from outside.
- **"FORECLOSED"** — closed off by the structure's own axioms, **with no agent involved.**

> ***"Emergentism forbids nothing here; the field forecloses it."***

And it is not a stipulation. It is a **proof**:

```
Suppose  y = N/0  with  N ≠ 0.
Then     0 · y = N.
But      0 · y = 0   in any field.
So       N = 0.      Contradiction. ∎
```

**It is not that the framework declines to assign a value. No such element exists, and the field proves it.** "Undefined" suggests an empty slot; **there is no slot.**

Note what is *not* affected: `0 × a = 0` is total, defined, and entirely unremarkable. Zero is absorbing and nothing departs. Only division fails, and it fails by non-existence.
