# The Fourth Churning

> **Many perennial problems may persist because an argument silently joins
> terms belonging to different types. Not every mystery is a type error.**

The Fourth Churning implements that conjecture as a falsifiable sidecar over
the frozen PQA-54 denominator. It does not rewrite the Third Churning or award
an earned philosophical result.

The diagnostic sequence is:

```text
native mystery → alleged typed join → conservative repair → answer mode
               → rival → discriminator → kill → survivor → residual
```

Four results are admissible: `TYPE_COLLISION`, `PARTIAL_TYPE_COLLISION`,
`NO_COLLISION`, and `UNDERDETERMINED`. A distinction is not yet a collision.
A collision is not yet a dissolution. A complete schema object is not a review.

The candidate grammar contains seven axes and twelve diagnostic subtypes. The
seven-axis rival is selected because it compresses the twelve subtypes without
erasing their different failure modes. The four-domain null remains in the
prior-art and compression matrix as a simpler control.
