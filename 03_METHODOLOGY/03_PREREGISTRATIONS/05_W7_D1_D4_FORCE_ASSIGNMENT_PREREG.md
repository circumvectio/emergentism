# W7 D1–D4 Force-Assignment Preregistration

## 1. Purpose and entry state

This is the test matrix for the Burri Sequential Force-Emergence Conjecture.
It freezes the comparison space before any assignment is treated as more than a
candidate. The intended claim is narrow:

> This matrix tests whether any specified bijective map earns a bounded,
> native-theory-recovering, held-out predictive role-affinity relative to
> frozen rivals. It cannot establish uniqueness or exclude the R2 many-to-many
> rival.

At entry, every candidate is **unscored**. No result, map, score, published
prediction, or independent replication exists. This document is a draft until
the exact native objects, equation versions, data sources, tolerances, hashes,
and analysis code are frozen. It may not be retrofitted after a result is seen.

The proposal does not say a Standard Model field exists only in one D-register,
that a register generated a force in time, or that the four registers are
literal spatial dimensions. It also does not test F5. That remains separately
bounded by W7e.

The stronger `SEWG-SERIAL` conjecture is recorded in the parent dossier but is
**not admitted to a run by this matrix**. It must pass the entry barrier in
§2A before a frozen successor protocol can test a dependency or cosmic-time
order.

## 2A. Entry barrier for the SEWG-SERIAL extension

A successor serial-emergence protocol may be frozen only after the proposer
supplies all of the following without using the desired ordering as a premise:

| Required object | Freeze requirement |
|---|---|
| stage carriers | An ordinary state space `Σ_i` for every stage; no Titan mark as a physical carrier. |
| transition maps | Exact `StageStep_i : Σ_(i-1) → (Σ_i,D_i,𝔣_i) or NoStage`; `D_i` is a register-role annotation, not a produced object, and the map is not yet a time-evolution law. |
| prior-stage obstruction | An `O_i` computed in the frozen lower-stage language before the proposed force law is introduced. |
| consistency witness | An independently checkable `C_i` showing what composition, transport, transition, or conservation debt the candidate force pays. |
| lower-vocabulary exclusion | Exclude the target interaction's fields, charges/currents, couplings, gauge connection or covariant derivative, target symmetry, equations, and observable; if `O_i` cannot be stated without them, the stage returns `NoStage`. |
| order semantics | Declare dependency order, cosmic-time order, or both; do not slide between them. |
| physical scale | Energy/temperature range, order parameter, boundary conditions, and conventions. |
| lower recovery | Accepted equations, domain, and tolerance recovered after every transition. |
| native-history rival | Standard Model + GR/EFT account, including electroweak unification and early-universe gravity assumptions. |
| discriminating output | One held-out result that differs across at least two orderings and the no-ladder rival. |
| bridge custody | If TLC-01 is invoked, independently freeze `AdmitSeedBridge : {finity_witness_ref, ordinary_carrier, transition_law, recovery_map, kill} → StageDescription[Σ_0] or NoBridge`; a FinityWitness neither instantiates nor causes the carrier. |

Until every row is filled and hashed, `SEWG-SERIAL` remains **not runnable**.
The present matrix can reject or fail force assignments; it cannot report a
serial cosmogenesis result.

No aggregate score is allowed. A candidate may be marked **survives** only
after every required packet field is complete, native recovery passes, a
permutation challenge has been run, and its held-out discriminator has been
independently replicated. A candidate may be **failed** at any earlier gate.
Failure of a candidate does not fail QCD, electroweak theory, GR, EFT, or its
D-register owner.

The frozen lower-stage vocabulary must exclude the target interaction's fields,
charges or currents, couplings, gauge connection or covariant derivative,
target symmetry, target-law equations, and target observable. `C_i` must be
testable before the target interaction is selected. If either `O_i` or `C_i`
requires any excluded target object, the row is circular and fails.

These floors are not bridges. They are minimum anti-handwaving constraints:

| Interaction | Must preserve before an Emergentist map is considered |
|---|---|
| S | Accepted QCD color and non-Abelian gauge structure in a declared tested domain. |
| E | Accepted U(1) or Maxwell/QED structure and an electromagnetic-specific observable in a declared tested domain. |

the word “emergence” in place of a native recovery is a failure.

## 6. D3-Q gate: the quantum-specific requirement

The proposer’s present intuition is that D3 must earn a force appropriate to
the quantum realm. This is a legitimate test demand, not a result.

For any candidate placing W at D3, the packet must predeclare all of:

1. a weak-specific left-chiral or parity-violating interaction structure;
2. a charged-current flavor-transition structure;
3. an exact detector, process, data source, and baseline model;
4. one held-out parity asymmetry, angular distribution, flavor-selection
   feature, branching feature, or comparable weak-specific observable; and
5. why the matched S-at-D3 and E-at-D3 bridges fail to recover the same
   observable without importing the weak structure by hand.

The following are **not** sufficient for D3-Q:

- a generic quantum state, amplitude, Hilbert space, path integral,
  superposition, measurement context, or gauge field;
- a statement that all forces are quantum; or
- a claim that gravity is not quantum.

If a generic quantum translation fits S, E, and W equally well, D3-Q = FAIL.
If the candidate needs weak-specific facts only as unexamined inputs, it has
not built a bridge. If it predicts no held-out result, it is a metaphor rather
than a physics candidate.
