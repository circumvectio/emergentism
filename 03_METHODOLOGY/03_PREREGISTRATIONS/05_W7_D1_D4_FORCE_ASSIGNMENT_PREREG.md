# W7 D1–D4 Force-Assignment Preregistration (v2.2)

## 1. Purpose and entry state

This is the test matrix for the Burri Sequential Force-Emergence Conjecture.
It freezes the comparison space before any assignment is treated as more than a
candidate. The intended claim is narrow:

> This matrix tests whether any specified bijective map earns a bounded,
> native-theory-recovering, held-out predictive role-affinity relative to
> frozen rivals. It cannot establish uniqueness or exclude the many-to-many
> rival.

At entry, every candidate is **unscored**. No result, map, score, published
prediction, or independent replication exists. This document is a draft until
the exact native objects, equation versions, data sources, tolerances, hashes,
and analysis code are frozen. It may not be retrofitted after a result is seen.

The proposal does not say a Standard Model field exists only in one D-register,
that a register generated a force in time, or that the four registers are
literal spatial dimensions.

The dated founder prior (D1→strong, D2→electromagnetic, D3→weak, D4→gravity)
is **PRIOR ONLY**. It records first-party provenance. Agreement with that prior
earns **no score**, no default, no priority, and no evidential advantage.

The stronger `SEWG-SERIAL` conjecture is recorded in the parent dossier but is
**not admitted to a run by this matrix**. It must pass the entry barrier in
§2A before a frozen successor protocol can test a dependency or cosmic-time
order.

Executable catalog, scoring lock, and protocol tests live in
[`force_assignment_v22/`](force_assignment_v22/).

## 6. D3→weak gate: chirality, not a generic quantum label

For any candidate placing W at D3, the packet must predeclare all of:

1. a weak-specific left-chiral or parity-violating interaction structure;
2. a charged-current flavor-transition structure;
3. electroweak structure (`SU(2)_L × U(1)_Y` or an equivalent frozen native
   formulation), including why E and W are not being smuggled as one unnamed
   joint placement;
4. an exact detector, process, data source, and baseline model;
5. one held-out parity asymmetry, angular distribution, flavor-selection
   feature, branching feature, or comparable weak-specific observable; and
6. why the matched S-at-D3 and E-at-D3 bridges fail to recover the same
   observable without importing the weak structure by hand.

The following are **not** sufficient for a D3→W placement:

- a generic quantum state, amplitude, Hilbert space, path integral,
  superposition, measurement context, or gauge field;
- a statement that all forces are quantum;
- a claim that gravity is not quantum;
- any slogan that names D3 as a generic quantum slot without chirality,
  parity violation, flavor change, and electroweak structure.

If a generic quantum translation fits S, E, and W equally well, D3-W = FAIL.
If the candidate needs weak-specific facts only as unexamined inputs, it has
not built a bridge. If it predicts no held-out result, it is a metaphor rather
than a physics candidate.

## 10. Freeze, run, and report procedure

Before a run:

1. fill every required packet field for the candidate;
2. freeze the full candidate text, sources, data version, code, analysis plan,
   tolerance, and candidate hash;
3. record the date and custodian;
4. run the native recovery test before inspecting held-out data;
5. run the permutation and rival comparisons with the same resources; and
6. publish the result, null, or kill beside the frozen packet.

Permitted post-freeze changes are additive error corrections with a new
identifier and an explicit statement that the earlier candidate was not
silently amended. A later candidate cannot inherit a positive outcome from a
different map.

Scoring lock (machine-checked in the v2.2 harness):

- founder-prior agreement contributes `0` points;
- F5 branch preference contributes `0` points;
- only completed packet gates may increment a diagnostic tally, and that
  tally is not a uniqueness proof.
