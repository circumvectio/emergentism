# v2.2 research contracts

This package makes three bounded conjecture tests machine-checkable without
claiming a result:

- `M4Compression.v1` freezes the corpus, target, coding cost, distortion floor,
  five comparator families, split, kill and survivor for a class-relative
  compression test.
- `SLWPBoundaryTest.v1` separates the proven section/fiber reconstruction
  asymmetry from the open ontological strong-emergence question.
- `ForcePermutationTrial.v1` freezes all 24 bijections and gives the proposer’s
  historical ordering no truth bonus.

Run:

```sh
python3 -B research_contracts.py --check
python3 -B tests/test_research_contracts.py
```

The package is standard-library only, performs no network calls, and contains
no model result or external validation.
