# Emergentism Frontier Protocol v1

**Status:** `OFFLINE-READY · [D]` only after the local checks below pass. This is
a reference protocol and deterministic public projection, not a live service,
research result, institution, payment rail, sensor intake, or model runtime.

**Semantic owner:** this document owns the five-object Frontier lifecycle. The
W7 science-integration register continues to own the twelve Grand Puzzle rows;
`living-map.json` continues to own public routing only; source documents and
result receipts retain their own semantics and tiers.

## Purpose

Every intelligence eventually meets an explanatory gap. This protocol makes one
such gap addressable without pretending to settle it:

```text
GapRecord
  → CandidateRecord
    → FrozenTestRecord
      → WorldReceiptRef
        → RevisionRecord
          → the next version of GapRecord
```

The arrows are admissible references, not automatic promotions. The five object
types are deliberately separate:

1. **`FrontierGap.v1`** points to a source-owned open question and preserves its
   native objects, equations, recovery obligation, rival, discriminator, kill,
   survivor, and distinct canonical/public state axes.
2. **`FrontierCandidate.v1`** is immutable raw intake. It must state a native
   frame, assumptions, serious rivals, no-placement rival, discriminator, kill,
   survivor, and run provenance. It never changes the gap by being filed.
3. **`FrontierFrozenTest.v1`** binds candidate identities to measures, controls,
   exclusions, predictions, data/code/stimulus hashes, a null, a kill, a survivor,
   and no-start gates before contact.
4. **`FrontierWorldReceiptRef.v1`** stores an immutable reference and provenance
   for appropriately custodied external evidence. The test actor may not issue
   independent verification for its own result.
5. **`FrontierRevision.v1`** is append-only adjudication. It references the prior
   gap hash and the evidence chain, preserves any survivor, records every removal,
   and creates a successor version rather than overwriting history.

`FrontierGraph.v1.schema.json` governs shape only. It creates no doctrine,
evidence, authority, result, or register movement.

## Launch state

The deterministic graph adapts the existing twelve W7 Grand Puzzle rows into
`FrontierGap.v1` references. It launches with:

```text
12 gap records
0 Frontier candidate records
0 Frontier frozen-test records
0 Frontier world-receipt references
0 Frontier revision records
```

These zeroes describe this protocol namespace only. They do not erase research
packets, tests, receipts, or corrections elsewhere in the corpus.

## Role firewall

| Role | May do | Cannot obtain merely by participating |
|---|---|---|
| Model | inspect, compare, propose, attack, prepare a candidate | truth, authority, authorship, independent validation |
| Sensor/data system | carry a bounded observation with calibration and custody | witnesshood, consent, semantic ownership |
| Human/institutional principal | supply a real mandate, resources, contest, and domain authorization | automatic truth or canonical placement |
| Evidence custodian | bind provenance and a result reference within its mandate | adjudicate the whole worldview |
| Emergentism | type, version, expose rivals/kills, preserve revision and Exit | own the territory or certify itself |

The public catalogue, schema, and worldview remain free to read. Any later paid
execution must price only bounded work such as compute, hosting, integration,
instrumentation, or independent review. Payment may never buy tier, truth,
canon, governance, authorship, authorization, silence, or removal of Exit.

## Deterministic commands

From this directory:

```text
python3 -B run_frontier.py generate
python3 -B run_frontier.py generate --check
python3 -B run_frontier.py validate
python3 -B -m unittest discover -s tests -p 'test_*.py'
```

The generator writes only the declared public projections under
`12_PUBLIC_SITE/frontier/`. It performs no network request and reads no secret.
Source-hash drift, state-axis collapse, missing rivals/kills/survivors, non-empty
launch result arrays, self-certified world evidence, or nondeterministic output
must fail the check.

## Kill criteria

Kill or replace this protocol if any public file becomes the semantic owner of a
gap, canonical execution status, evidence tier, or revision; if canonical and
public routing states collapse; if a candidate automatically promotes a gap; if
test bytes can change after contact without a new identity; if the actor certifies
its own world receipt; if a revision erases its predecessor; if source hashes can
drift without failure; or if the public surface implies live jobs, payment,
credentials, sensor intake, totality, or institutional authority.

The means is the message. The ends are the limits.
