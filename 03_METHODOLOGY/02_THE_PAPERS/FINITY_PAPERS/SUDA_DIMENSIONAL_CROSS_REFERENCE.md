# Suda Structures — Optional Register Crosswalk

This compatibility path no longer assigns Suda structures to physical or
ontological dimensions. `D1=space`, `D2=time`, `D3=form`, and similar identities
are not Emergentist register definitions. A theorem in another formal system
retains its own premises and proof; placing it in a Rosetta row transfers no
evidence.

Where useful, a source structure may be compared `[I]` with one or more roles:
distinction (D1), configuration (D2), transformation/persistence (D3), actual
carrier/event (D4), or merely possible content (D5). The mapping must state the
preserved relation, rival mapping, domain source, and kill criterion. D0 and D6
are boundary roles, not theorem containers.

are superseded. Its original remains at Git blob
`3be1608303b3c2ca47adfd93d7e045a977981548`.
