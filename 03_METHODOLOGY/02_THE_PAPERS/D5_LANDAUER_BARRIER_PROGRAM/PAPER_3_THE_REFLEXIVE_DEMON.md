# Paper 3: The Reflexive Demon

**Program home:** [The D5 Landauer Barrier Program](README.md)

## Corrected thesis

An actual D4 agent does not inspect a fixed future. It builds an actual D4
model whose content includes possible D5 alternatives. Modeling,
communication, ranking, commitment, and action are themselves events in the
territory; they can change other agents' later models, selections, and the
environmental transition.

This is reflexivity, not physical retrocausality. The possible future has no
backward causal channel. A present model token about that future changes a
present action distribution.

## Three gaps

1. **Cognitive gap:** territory differs from the actual model token.
2. **Execution gap:** represented intention differs from performed action.
3. **Outcome gap:** expected consequence differs from the actual outcome.

The typed Soul Loop keeps those gaps inspectable:

```text
χ_t(X_t, Ω_t, M_t, V_t, U_t) -> (a_t, q_t)
(X_{t+1}, r_{t+1}) ~ K_t(. | X_t, a_t, E_t)
Loop(M_t, G_t, q_t, r_{t+1}) -> (M_{t+1}, G_{t+1})
```

All functions, tokens, receipts, and updates shown here are actual D4 events or
records. `Ω_t` alone denotes possible D5 content. `q_t` records commitment;
`r_{t+1}` records the environment-returned outcome.

## Dynamical signs

Negative feedback means a declared error measure decreases. Positive feedback
means divergence or self-confirmation increases. These signs are dynamical,
not moral. A reinforcing loop can help or harm; Justice requires separate
assessment of authorization, payers, beneficiaries, and consequence bearers.

## Falsifiers

- treating the option field as static after actual communication or action;
- calling the actual agent, model, ranking, selection, or institution D5;
- letting the selector manufacture its own outcome receipt;
- treating reflexivity as proof that future events signal backward in time;
- ignoring strategic agents who respond to being modeled.
